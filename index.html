    Research

    My research centers on XR for teleoperation and human-robot interaction and on 3D immersive reconstruction with Gaussian splatting. Three threads:

    XR teleoperation with real-time 3D Gaussian splatting scene memory

    I use 3D Gaussian splatting, a fast way to rebuild real objects in 3D from camera images, to bring the physical world into XR. On a Meta Quest 3, our pipeline digitizes real objects in 2–4 seconds without per-scene training, as interactive proxies that can be grabbed, inspected, and used to select the physical objects they came from. For teleoperation, a bimanual XR technique lets an operator give a robot high-level assembly goals as nested groups of object constraints, leaving choices such as where to build a subassembly to the robot software.

    Fast Digitization (IEEE VR 2026 demo) Bimanual Assembly Hierarchies (IEEE VR 2026 poster)

    XR authoring for human-robot collaboration

    Many physical tasks only need objects placed relative to each other, not at fixed spots in the room. I design XR interfaces that let people specify just those constraints and delegate the details to a robot. Delegate the Details pairs an XR authoring interface with a robot planner for assembly constraints; we evaluated it in a 20-participant study with offline execution on a UR5e robot arm. Earlier work introduced relative 6DoF pose specification for VR task guidance and compared permanent and temporary proxies (copies of objects used for selection and manipulation), finding permanent proxies more efficient for hard reselection and preferred.

    Delegate the Details (IEEE ISMAR 2026) VR Task Guidance (IEEE ISMAR 2025) Permanent Proxies (IEEE VR 2025)

    Toolkits for XR development

    XR applications wire many scene objects together with intricate application logic, which makes them hard to build and debug. MercuryMessaging is a Unity toolkit for routing messages and events between objects; I released MercuryMessaging 2.0, which includes networking APIs and speeds up VR app and user study development up to two-fold. Its XR GUI lets developers view and edit the relationships and interactions between scene entities from inside XR.

    XR GUI for ECS Messages (IEEE ISMAR 2024) MercuryMessaging on GitHub
